空杯记账

iPhone 快捷指令一键记账 · 账存在你自己的飞书多维表格 · 手机上按周、按月看花在哪

全程免费（飞书免费版 + Vercel 免费版），开源，数据只在你自己手里。

 

快速开始 · 使用说明 · 常见问题

它是什么

付完款，按一下手机侧边的操作按钮（或者轻点背面两下）：快捷指令截屏认出金额，你选个类目、写句备注，这一笔就记进了你自己的飞书多维表格。打开主屏幕上的「空杯记账」，这周、这个月花了多少、花在哪，一眼看清。

  • 记账：截屏自动认金额；收入自动记成正数；记完弹「记好了」，失败会弹出原因，不会悄悄丢账
  • 看账：周、月一键切换，顶部时间条点一下或拖一下就换周；日常花销和房租、出行、大额这些「单独列出」的分开算
  • 每天：周视图是柱状图，月视图是日历热力图，点某天就看那天的明细；分类占比、整月明细随手可查
  • 年复盘：全年月均、每月折线，点某个月看那个月花在哪；还有「这一年」月份列表、分类走势、最大的 10 笔、每月存下多少
  • 主题句：给每周、每月、每年写一句「这段时间花在什么上」，过几个月回头看，一眼知道那个月干了什么
  • 改账：点一笔就能改金额、分类、备注，直接写回飞书
  • 像 App 一样：添加到主屏幕，打开就是上次的数据；日间、夜间两套配色；有新版本自动更新
  • 数据在自己手里：账存在你自己的飞书表，看板和接口跑在你自己的 Vercel 上，作者看不到任何数据

快速开始

大约半小时。每一步点哪里，使用说明 · 自己搭一套 里都写了。

  1. 复制飞书表格模板：打开 空杯记账 · 模板，登录飞书后「创建副本」到你的云空间。
  2. 建一个飞书应用：在 飞书开发者后台 建一个自建应用，开通多维表格权限、发布，再把它加成这张表的「文档应用」（可编辑）。记下 App ID 和 App Secret。
  3. 一键部署到 Vercel：点上面的 Deploy 按钮，填下面 6 个环境变量。
  4. 装到手机上：用 Safari 打开你的看板 → 分享 →「添加到主屏幕」。主页上会出现「装上记账快捷指令」，跟着三步装好，记一笔就完成了。
环境变量 填什么
FEISHU_APP_ID / FEISHU_APP_SECRET 第 2 步飞书应用的凭证
BASE_TOKEN 表格网址里 /base/ 后面、? 前面那一段
TABLE_ID 表格网址里 table= 后面那一段
API_TOKEN 看板的访问口令，自己编一个
ACCOUNTING_SECRET 记账口令，自己编一个长一点的。不用记：看板会把它拼进「专属记账地址」，帮你复制给快捷指令

在国内、手机不开梯子用：xxx.vercel.app 在国内打不开，要在 Vercel 里绑一个自己的域名（一年十几块），见 使用说明第 4 步。

怎么工作

记账：快捷指令 → 你的 Vercel（/api/accounting）→ 你的飞书多维表格
看账：你的飞书多维表格 → 你的 Vercel（/api/records）→ 看板（主屏幕上的网页 App）
  • 记账接口和看板放在同一个 Vercel 项目里（函数在香港节点）；快捷指令用的「专属记账地址」由看板生成，自带记账口令
  • 看板打开先显示手机里的缓存，再去同步（只拉上个月 1 号至今，更早的用缓存）
  • 飞书免费版每月 1 万次接口额度：记一笔用 1 次，看板同步一次用 1 次，一个人一个月一般几百次

常见问题

  • 要花钱吗？ 不用。飞书免费版、Vercel 免费版（Hobby）就够；只有国内不开梯子用才需要买个域名。
  • 安卓能用吗？ 看板能用，任何手机浏览器都行。记账快捷指令只有 iPhone 有；安卓可以直接在飞书表里记，或者用自动化工具往记账接口发请求（格式见 使用说明第 1 节）。
  • 作者能看到我的账吗？ 看不到。账在你的飞书表，接口在你的 Vercel，看板不接任何统计和广告。
  • 想换类目？ 要同时改三处：飞书表「账单类目」的选项、server/code/accounting.js 的 CATEGORY_OPTIONS、web/src/config.ts 的 SEPARATE_CATEGORIES（哪几类单独列出）。
  • 更多问题见 使用说明 · 常见问题；看板页脚的「文档」也是同一份。

本地开发

cd web && npm install && npm run dev   # 不连接口：用 src/demo 里编的账目
cd web && npm test                     # 前端测试
cd server && npm test                  # 接口测试（零依赖）
  • web/：看板（Vite + React + TypeScript，图表手写，没有图表库）
  • api/：Vercel 函数入口；逻辑在 server/code/（读账、记账、改账、主题句、专属记账地址）
  • docs/使用说明.md：用户文档；docs/空杯记账.shortcut：记账快捷指令（和看板引导里装的是同一个）
