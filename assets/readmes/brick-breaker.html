霓虹破壁 · Neon Breaker 是一个单文件 HTML 打砖块小游戏。它用原生 JavaScript、HTML5 Canvas 和 Web Audio API 实现，不需要安装依赖，也不需要构建流程，打开 打砖块.html 就可以直接游玩。

这版做了中度减法：保留肉鸽协议、BOSS 和霓虹反馈，但把体验重新收束到「控板、控球、打砖」。留下来的每张协议卡、每个道具和每个主动能力都服务于明确目的：控球、清场、破钢/核心、容错或处理 BOSS 压力。

快速开始

直接双击或用浏览器打开：

打砖块.html

如果浏览器对本地文件权限比较严格，也可以在项目根目录启动一个本地静态服务：

python3 -m http.server 8765

然后访问：

http://127.0.0.1:8765/打砖块.html

操作方式

操作 说明
A / D 左右移动挡板
方向键 ← / → 左右移动挡板
鼠标移动 控制挡板位置
Enter / 鼠标左键 开始、发射小球、选择协议卡

P 暂停 / 继续
R 重开当前 run
M 静音 / 恢复声音
1 / 2 / 3 在协议选择界面直接选择对应卡牌

能量槽充满后，不再释放独立大招；下一次量子刺会自动升级为更宽、更高伤害的「霓虹刺」。

核心循环

  1. 在菜单点击或按键开始游戏。
  2. 从 3 张起手协议中选择 1 张，确定本局方向。
  3. 进入关卡，用挡板控制小球击碎砖块和 BOSS。
  4. 接住掉落道具，积累能量，让下一次量子刺变成霓虹刺。
  5. 通关后从 3 张协议卡中选择 1 张永久强化。
  6. 推进 8 关，在生命耗尽前击败最终 BOSS。

关卡流程

关卡 敌人 / 节点 设计重点
1 像素史莱姆 小阵型，练习控板和反弹角
2 振动针 竖向阵型，训练打顶部核心
3 数据蜂巢 更密的砖块与爆炸砖连锁
4 镜像兽 左右镜像伤害，鼓励找高价值角度
5 阅读者 BOSS 首个 BOSS，出现可预判弹幕
6 巨人 钢砖和核心簇，考验破防能力
7 数据蜂巢强化 更高密度，检验 build 覆盖能力
8 最终阅读者 最终 BOSS，考验量子刺和控球稳定性

普通关不再发射敌弹；BOSS 关保留弹幕压力。量子刺可以清理/反转路径上的敌弹。

协议卡系统

协议卡分为 4 个类型：激光、多球、重击和支援。起手协议池只包含 4 张方向卡：电磁炮台、分裂核、核爆者、磁吸。之后的关间选择会根据已有卡牌过滤依赖卡，避免出现拿了但没有效果的协议。

类型 名称 效果 设计职责
激光 电磁炮台 每 1.5 秒自动射出 1 道激光 稳定补刀边角砖
激光 过载 激光穿透，1 道击穿 3 砖 强化炮台清线
激光 散射 炮台激光改为 3 路扇形齐射 扩大覆盖面
多球 分裂核 每关开始时一变三 提高覆盖，增加控球风险
多球 时空回响 真实球撞砖时生成短暂撞击副球 奖励主动打砖与连锁角度
多球 碎片球 球破砖瞬间向四方分裂弹丸 强化破砖爆发
重击 核爆者 破核心时引爆 130px 范围 核心清场
重击 导体 钢砖/核心受击时向相邻砖传导伤害 破钢与核心联动
重击 欧米伽 核心引爆范围翻倍并额外伤害 核心爆破上限
支援 磁吸 球靠近挡板时自动吸引 容错与控球
支援 凝固 每关 1 次，最后一球危险时自动凝固 0.35 秒 自动救险，不增加操作键
重击 复仇 失球时锁定最近目标列射出免费量子刺 失败反击，减少挫败

道具与资源

道具现在必须被挡板接住才生效，错过会掉出画面。这样道具是一个移动决策，而不是自动奖励。

名称 效果 设计职责
多球 额外生成 2 颗球 临时扩大覆盖
加长 临时加宽挡板 容错窗口
慢速 临时降低球和弹幕速度 稳定控球
穿透 临时让球击穿非特殊砖 清密集砖

能量来自击砖、破核心、连击和 BOSS 伤害。能量满时，下一次量子刺自动升级为霓虹刺。

主动能力

量子刺 / 霓虹刺

量子刺由鼠标右键或 Shift 触发，从挡板中心向上射出竖直光束，击中同一列砖块，并把路径上的敌方弹幕转化为友方弹丸。

能量满时释放的下一次量子刺会变成霓虹刺：光束更宽、伤害更高，适合处理 BOSS、核心簇和危险弹幕。

技术栈

  • HTML5 Canvas：负责所有游戏画面绘制。
  • 原生 JavaScript：实现状态机、实体更新、碰撞、卡牌和关卡逻辑。
  • Web Audio API：在浏览器内实时合成音效。
  • localStorage：保存最高分。
  • 零依赖：不依赖 npm、打包器或外部素材。
