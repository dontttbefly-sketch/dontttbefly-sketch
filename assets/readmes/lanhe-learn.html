这是公司内部的私有项目，源码、课程视频与截图不公开。以下只展示脱敏后的平台设计与工程做法。

部门新人培训平台：每门课 = 一个视频 + 一张思维导图 + 一套 PPT，新人每天解锁一关。

它不是一次性的课件页面，而是一套内容和代码分离的平台：播放页、导图、PPT 查看器、进度和解锁全部通用，不认具体课程。加一门课只写内容，加一条岗位路径只加一份清单，页面框架不用改。

平台结构

学习路径 Track（如：售前 · 新人必修）
  -> 课程 Course × N（第 N 天解锁第 N 关，未上线的课先占位）
       -> 内容层：视频 + 思维导图（带章节时间点）+ PPT 截图
  -> 通用层：播放页 / 导图跟随 / PPT 查看器 / 进度与解锁

学习体验

  • 三屏联动：导图节点绑定视频时间点，点节点就跳到对应位置；进度条显示章节刻度，导图和 PPT 跟着播放进度走，每章看完自动打 ✓。
  • 真的看完才算完：第一次观看不能快进，只统计实际看过的片段，覆盖 95% 才算完成；完成后随意拖动复习。
  • 闯关片廊：首页是浅色「白墙画廊」，点进课程「关灯」进入深色影院，返回时「开灯」。
  • 照顾办公电脑：按设备性能分级，低配机器自动关掉重效果。

内容生产流水线

平台的另一半是工具链：新视频进来，按固定步骤就能做成一关。

  • 章节自动对齐：ffmpeg 逐秒截取烧录字幕 → macOS Vision 离线识别 → 生成「时间 → 字幕」时间线，再对照逐字稿定章节点。37 分钟的视频约 5 分钟跑完，对齐了 49 个章节时间点。
  • PPT 一键处理：截图里的敏感信息用不可还原的实色斜纹打码 → 转 WebP 大图 + 缩略图 + 模糊占位 → 自动生成清单。
  • 中文字体按需子集化：构建前扫描页面用到的汉字，只截取这些字（约 250KB），不依赖外部字体服务。
  • 可交给智能体接手：写明「来了一个新视频，做成一关」的完整步骤，新课可以由 AI 照样板课生产，人来审核。

工程质量

  • React 19 + TypeScript + Vite，产物是纯静态文件，任何静态托管都能部署。
  • Vitest 校验内容一致性：每页 PPT 恰好一个主归属、章节时间按顺序递增、课程统计与数据一致。
  • 进度存储走 ProgressStore 接口：现在存在本机浏览器，换成云端只需新写一个实现。

设计约束

面向真实的内部培训，以下三条贯穿整个平台：

  • 内部数据不外泄：截图打码，部署必须加访问控制
  • 导图人工审核：AI 写的都是草案，负责人确认后才上线
  • 矛盾不自己裁决：逐字稿、视频、PPT 说法不一致时，标注「待确认」交给负责人
