一个基于 React + TypeScript + Three.js + Vite 构建的沉浸式宇宙学习网页。项目用精选真实天文数据作为可交互锚点，并通过程序化星场、银河结构、尘埃云、星云层和尺度说明，帮助用户在浏览器中理解太阳、银河系结构、邻近恒星、星团、星系群与可观测宇宙之间的空间关系。

项目简介

这个网页不是传统的静态科普文章，而是一个可以自由拖拽、缩放、搜索和切换图层的 3D 宇宙探索器。界面以中文学习面板为核心，配合可点选天体、真实度标签和来源链接，区分“实测数据”“结构模型”和“艺术近似”，让用户能看见画面，同时知道画面哪些部分来自真实观测，哪些部分是为了教学和可视化而构建的模型。

适合用于：

  • 天文科普展示和课堂演示
  • WebGL / Three.js 交互式可视化案例
  • React + TypeScript 前端项目学习
  • 真实数据与程序化视觉结合的原型探索

主要功能

  • 全屏 3D 宇宙场景：包含银河盘、中央核球、旋臂、尘埃暗带、星云提示、恒星晕、星团和更大尺度的宇宙结构。
  • 精选天体锚点：内置太阳、银河系中心、Sagittarius A*、猎户臂、本地臂、盾牌-半人马臂、英仙臂、人马臂等可搜索目标。
  • 真实度标签：每个数据或图层用“实测”“模型”“艺术近似”等标签说明可信边界。
  • 图层控制：可开关精选天体标记、近身恒星实体、银河薄盘、银河厚盘、旋臂、星云、尘埃、星团、星系群等图层。
  • 学习面板：展示当前目标的简介、关键事实、物理画像、真实尺度、观测限制和参考来源。
  • 相机预设：支持太阳位置、中央棒核、完整俯视、边缘侧视、恒星晕、球状星团、猎户臂、可观测宇宙等视角。
  • 自由探索交互：支持鼠标拖拽旋转、滚轮缩放、WASD/QE 平移。
  • 测试覆盖：核心数据、坐标换算、视觉质量、星体光学、图层逻辑和程序化生成逻辑均有 Vitest 单元测试。

技术栈

  • React 19：负责界面状态、面板、搜索、图层控制和学习内容渲染。
  • TypeScript：约束天体数据、图层模型、视觉质量配置和工具函数。
  • Three.js：驱动 WebGL 3D 场景、粒子星场、ShaderMaterial、InstancedMesh 和相机交互。
  • Vite：提供快速开发服务器和生产构建。
  • Vitest：覆盖核心计算逻辑与数据行为。

数据与视觉边界

项目第一版不是完整 Gaia 星表浏览器，也不是严格的 N-body 物理模拟。它采用精选真实资料作为学习锚点，再用程序化模型补齐大尺度银河结构和沉浸视觉效果。

需要特别注意：

  • 天体位置、距离、尺度和说明优先服务于交互式学习，不等同于专业科研软件。
  • 银河旋臂、尘埃云、星云纹理和宇宙网结构是可视化模型，用来表达结构关系和空间层次。
  • 近景恒星实体只在适合观察的尺度下作为视觉辅助出现，不代表每颗恒星的真实物理半径。
  • README 截图来自本地运行页面，用于展示当前视觉状态。

交互说明

  • 鼠标拖拽：旋转观察视角
  • 滚轮：拉近或拉远
  • WASD：水平平移
  • Q / E：垂直平移
  • 顶部按钮：切换预设观察位置
  • 左侧搜索框：查找并定位天体或银河结构
  • 左侧图层面板：打开或关闭不同视觉层
  • 右侧学习面板：查看当前目标的事实、尺度和资料来源

构建与部署

生产构建输出在 dist/ 目录：

npm run build

当前仓库使用 GitHub Actions 发布到 GitHub Pages。推送到 main 后，workflow 会安装依赖、运行测试、执行生产构建，并将 dist/ 发布到：

https://dontttbefly-sketch.github.io/milky-way-3d-explorer/

构建完成后，也可以将 dist/ 部署到任意静态站点服务，例如 Vercel、Netlify、Cloudflare Pages 或自托管静态服务器。

公开发布安全提醒

这个项目不需要运行时密钥。公开发布前请确认没有提交 .env、.env.*、.state/、rules.json、本地日志、访问 token、Webhook URL 或其他敏感信息。真实密钥不应出现在浏览器端源码或 GitHub Pages 构建产物中。
