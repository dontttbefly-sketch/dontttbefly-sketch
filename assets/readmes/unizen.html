锚定一事，方可漫游人生。

Unizen 是一款 local-first（本地优先）的 macOS 原生应用，用于长期运营个人项目：每个项目打开就是一本「项目书」（Project Book），未完成的事项留在项目里持续操作，完成的工作沉淀为可追溯的 Progress 历史。

它不是任务管理器，也不是又一个 GTD 工具 —— 它解决的是**「一个项目做了半年，我还能立刻看懂它、接得上、写得回」**这个问题。

核心理念

原则 含义
User First 降低长期项目的维护成本，不增加流程负担
Project Book First 未完成事项只在当前项目书里操作，没有用户可见的全局收件箱
Title First 新建事项只需要一个标题；归属由当前项目隐式提供
Progress Is The Asset 完成即产生 Progress，不把「已完成」重建为主视图
No Pressure Mechanics 没有待办清单、逾期状态、评分、连续打卡或强制规划
Local Ownership 数据本地优先、可导出 JSON/Markdown，导入替换前先保护既有数据
Mac-Native Utility 命令、快捷键、右键菜单、焦点与无障碍都应是原生手感
AI Proposes, User Decides AI 只能提议，必须用户显式确认才能写入正式项目事实

AI 协作协议（本项目的核心设计）

Unizen 与外部 AI（如 Codex）的分工是：

Unizen 保存项目事实  ──→  AI 负责分析、拆解与执行
        ↑                        │
        └── 只接受「用户确认后」的写入  ←── AI 只能提交字段级建议

AI 通过可选的 Project Genesis 访谈，在项目书内生成一份本地暂存的提纲（Staged Blueprint），只有用户逐项确认，才会变成正式的「项目 → 目标 → 事项」。AI 永远不能直接写规范数据。

子项目：foucs（FuJianFocus）

FuJianFocus/ 是仓库内的独立 macOS 菜单栏工具：用一张常驻小便签管理当前工作清单，并在专注某件事时保存分钟级专注会话。

cd FuJianFocus
swift test && swift build && swift run FuJianFocus
./Tools/create-app-bundle.sh
open .build/app/foucs.app

开发

环境：macOS + Swift 6 / Xcode 命令行工具

# 主应用
cd Unizen
swift build
swift test

# 核心模块
cd ../FocusBridgeCore && swift test
cd ../LocalDataSafetyCore && swift test

数据位置：~/Library/Application Support/Unizen/（本地优先，不上传）

设计基调：Apple Daylight Ledger

  • 浅色是暖纸质感，深色是夜间纸面，石墨色文字 + 克制的品牌粉
  • 紧凑书架 + 密集账本，不做卡片墙，不做通用 AI 界面
  • 具体视觉与动效规范见 docs/superpowers/specs/ 下的设计规格

状态

个人项目，持续开发中。核心模块（Unizen / FocusBridgeCore / LocalDataSafetyCore）有单元测试覆盖。
